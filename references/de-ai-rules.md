### 1.4 过度模糊限制语（避免堆砌）

以下词汇单独使用尚可，但禁止堆砌（一段出现2个以上视为堆砌）：

- 大概率、可能、通常、一般来说、往往、多半、似乎、大概、也许、差不多、基本上、相对来说
- 替换方向：用确定语气或具体数据替代，如"通常会"→"一般会"或直接说结论

## 二、强制转换清单

### 2.1 句式转换

| 原始特征 | 转换规则 | 示例 |
|---|---|---|
| 长句（超过30字） | 拆成2-3个短句，每句15-20字 | "通过引入先进的算法模型实现了数据处理效率的大幅提升" → "用了新算法，数据处理快了不少" |
| 复杂被动式 | 改成主动式 | "该方案被广泛应用于多个领域" → "好些领域都在用这个方案" |
| 名词化表达 | 改成动词表达 | "进行了一次全面的评估" → "全面评估了一下" |
| "对…进行…" | 直接用动词 | "对数据进行分析" → "分析数据" |
| 双重否定 | 改成肯定 | "并非不可能" → "有可能" |
| 形式主语 | 去掉"它""这"等 | "它能够有效地解决问题" → "能解决问题" |

### 2.2 逻辑连接词转换

| 生硬连接词 | 口语化替代 |
|---|---|
| 因此 | "所以""这样一来" |
| 然而 | "但是""不过""话虽这么说" |
| 此外 | "对了，还有一点""另外""还有" |
| 同时 | "一边""另外""同时" |
| 从而 | "这样一来""就" |
| 进而 | "然后""接着" |
| 另外 | "还有""对了" |
| 反之 | "反过来" |
| 否则 | "不然""要不" |
| 尽管如此 | "话虽这么说""但话说回来" |
| 与此同时 | "同时""另外" |
| 综上所述 | "说到底""说白了" |

### 2.3 口语锚点（每篇至少使用1-2处）

在合适位置自然插入以下词语，让文本有"人味"：

- **引发共情**：你想想看、我跟你说、说实话、老实讲、不瞒你说
- **转折口语**：话说回来、不过话又说回来、但话又说回来
- **总结口语**：说白了、说到底、归根到底
- **补充口语**：对了，还有一点、哦对了、顺便说一句
- **感叹口语**：这玩意儿、这事儿、你别说、还真别说
- **强调口语**：真的、确实、讲真、说真的
- **过渡口语**：其实吧、怎么说呢、要我说

### 2.4 情感注入

在客观信息中自然加入个人评价或感受：

- "这个方案很好" → "我觉得这个方案贼棒"
- "这种方法效率很高" → "这方法用起来是真的快"
- "需要注意以下几点" → "有几个坑得避开"
- "该技术具有广阔的应用前景" → "这技术以后肯定能火"
- "建议采用此方案" → "我建议用这个，确实好使"

## 三、检查清单

重写完成后，逐项检查：

- [ ] 全文无禁用词（对照1.1清单）
- [ ] 段落开头无"首先/其次/然后/此外/最后"
- [ ] 全文无"此外/然而/值得注意的是/综上所述/总而言之"
- [ ] 无僵化句式（在…方面/通过…得以实现/作为…的重要组成部分）
- [ ] 模糊限制语未堆砌（一段不超过1个）
- [ ] 长句已拆短（无超过30字的单句）
- [ ] 被动式已改主动
- [ ] 至少1-2处口语锚点（说白了/其实/你想想等）
- [ ] 有个人情感/评价注入
- [ ] 原文核心信息和逻辑未改变
